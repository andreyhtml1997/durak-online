# Дурак - интернет-сервер

Раздаёт веб-версию игры и пересылает ходы между игроками (WebSocket `/lan`).
Состояние партии хранит телефон создателя стола, сервер только ретранслирует сообщения.

- запуск: `npm install && npm start` (порт из `PORT`, по умолчанию 8080)
- проверка: `GET /health`
- хостинг: Render, конфиг в `render.yaml`
